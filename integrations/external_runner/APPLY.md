# Apply the loader patch

Run this on the live `run_ta.py`. It writes a separate file and does not change the original.

```bash
python integrations/external_runner/patch_exact_loader.py \
  /workspace/tradingagents-runs/run_ta.py \
  --output /tmp/run_ta.patched.py
```

Exit 0 means the output contains exactly one replacement of this block:

```python
sent_path = RUN / f"sentiment_digest_{TICKER}_2026-11-15.md"
if not sent_path.exists():
    # fall back to any digest for this ticker
    candidates = sorted(RUN.glob(f"sentiment_digest_{TICKER}_*.md"))
    sent_path = candidates[-1] if candidates else sent_path
sent = sent_path.read_text() if sent_path.exists() else ""
```

Any other text, including a missing comment or different quotes, exits 2 and writes nothing. Do not use `run_ta_hotfix.diff` (invalid `@@`). The reviewable diff generated by `difflib` is `sentiment_loader_hotfix.diff`. `git apply --check` succeeds on a file whose surrounding lines match that fixture. On the live file, use the patcher, then review `/tmp/run_ta.patched.py` before you copy it.

`DATE` in the new filename is the CLI date the runner already passes. In the current runs that is the US price-session date (`2026-11-16`), not `decision_at` (`2026-11-17`). `sentiment_digest_BABA_2026-11-16.md` is the operator summary compiled on 2026-11-17. This patch does not create it.
